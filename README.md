# 辰屿 Pro Skill

当前版本 **v2.13.0**（以 `chenyu-pro version` 为准；重跑安装命令即升级）

短剧剧本生产平台的 AI Agent 操作员 Skill——装进 Codex / Claude Code 后，直接对 Agent 说
"帮我把这个剧本洗成日本版，30 集"，Agent 自动完成：授权检查 → 积分预估 → 提交生产 →
盯进度 → 交付整包剧本。支持 9 个目标市场洗稿、网文改编、制片级导演拍摄版。

## 一行安装（Windows，需 Node 18+）

```powershell
irm https://raw.githubusercontent.com/hieason4567-jpg/chenyu-pro-skill/main/install.ps1 | iex
```

装完会自动显示下面的使用说明（之后随时 `chenyu-pro guide` 再看，`chenyu-pro guide 视频` 只看一节）：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 辰屿 Pro Skill v2.13.0 使用说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 开始：绑定积分 KEY（只做一次）
  ──────────────────────────────────────────────────────
  chenyu-pro key set <你的积分KEY>
  chenyu-pro credits            ← 看到用户名和余额就成功了
  ※ 之后在 Codex / Claude Code 里用大白话说需求，命令由 Agent 自己跑，你不用记命令
  ※ 拿不准手上的文件该怎么处理，就说「看看这个文件该怎么用」

■ 一、视频反推剧本 —— 手上只有成片视频
  ──────────────────────────────────────────────────────
  ※ 计费：每 240 秒视频 30 积分（不足按一段算），Agent 先报价，你同意才扣；后面写剧本不扣积分

  ◆ 场景 1：整部剧 1:1 还原
      ▶ 你说：「把 D:\短剧\霸总 里第1-30集视频反推成剧本，1:1 还原，台词保留原句」
      ✓ 得到：分集剧本 + 全局资产清单 + 形象表.json + 交付审核报告
      ※ 过程：分析视频 → 整理人物/场景/道具 → 逐集写剧本 → 格式和交付检查 → 写入原片时长

  ◆ 场景 2：反推的同时洗稿
      ▶ 你说：「把这 20 集视频反推，同时洗成现代都市背景，人名全换」
      ✓ 得到：洗好的新剧本（剧情节拍不变，设定和名字换掉）+ 形象表.json

  ◆ 场景 3：先分析前几集，后面再追加
      ▶ 你说：「先分析第1-10集 …（过几天）… 把第11-20集追加到同一部剧」
      ※ 同一部剧一定追加到同一个项目，人物会跨集合并；不要一集开一个项目

  ◆ 场景 4：中途断网 / 想重新取分析稿
      ▶ 你说：「上次那部剧的分析稿重新取回来」
      ※ 不重新分析，不扣积分

  ◆ 场景 5：人物认错了（一个人被拆成两个、两个人被合成一个）
      ▶ 你说：「用已有分析结果重建人物身份」
      ※ 不重看视频，只扣少量文本分

  ◆ 场景 6：视频在链接里
      ▶ 你说：「分析这个链接里的视频：https://…/ep01.mp4」

■ 二、小说改编成短剧 —— 手上是小说 / 网文 / 大纲
  ──────────────────────────────────────────────────────

  ◆ 场景 1：整本改编
      ▶ 你说：「把 D:\小说\重生千金.txt 改编成 60 集短剧，每集 90 秒，节奏要快」
      ✓ 得到：分集剧本（每集开头有钩子、结尾有悬念）+ 形象表.json

  ◆ 场景 2：先试几集看风格
      ▶ 你说：「先把前 5 章改成 5 集，我看看风格」
      ※ 满意后说「继续改后面的」，人物和形象沿用前面的设定

■ 三、剧本洗稿 —— 手上是分集剧本（第N集…）
  ──────────────────────────────────────────────────────
  ※ 所有洗法都走：定人名设定 → 逐集写 → 机器检查 → 分段审稿 → 全剧主审 → 修订 → 通读，全部通过才交付，附审核报告

  ◆ 场景 1：只改角色名（最常用）
      ▶ 你说：「这部剧只改角色名字，其他都不动」
      ✓ 得到：名字和称呼全剧统一替换，台词其余一字不改，没有旧名残留

  ◆ 场景 2：1:1 整理成标准格式（不洗）
      ▶ 你说：「按原剧本 1:1 整理成标准格式，剧情台词都不改」

  ◆ 场景 3：换背景 / 换设定
      ▶ 你说：「把这部古装剧洗成现代豪门背景，身份职业都换成现代的」
      ※ 剧情功能不变，道具、身份、称谓按新世界等价替换（如 玉佩 → 股权书）

  ◆ 场景 4：女频改男频（或男频改女频）
      ▶ 你说：「把这部剧女频改男频，女主改成男主，剧情节奏不变」
      ※ 代词、称谓、外貌全部换性别；男女不通用的情节按功能等价替换

  ◆ 场景 5：降重 / 去重
      ▶ 你说：「这部剧要降重，台词全部换说法，剧情不变」
      ※ 每句台词保留功能（威胁、打脸、反转…），换句式和措辞

  ◆ 场景 6：出海
      ▶ 你说：「把这部剧洗成日本版」
      ※ 也可：欧美英语、拉美西语、巴西葡语、韩国、泰国、越南、印尼
      ※ 人名、地名、机构、货币、称谓按当地本地化，剧本正文用中文写

■ 四、人物形象设计 —— 让客户端照表建卡，不用自己猜
  ──────────────────────────────────────────────────────

  ◆ 场景 1：给剧本做形象设计
      ▶ 你说：「给这部剧的所有人物做形象设计，导出形象表」
      ✓ 得到：形象表.json：每个形象都有长相、发型、服装配色、音色；场景和道具有出图描述
      ※ 上传客户端后直接出图，不用再等客户端设计

  ◆ 场景 2：已有形象表，只补缺的
      ▶ 你说：「形象表里没设计的形象帮我补上」

■ 五、已分镜爆款工程改写 —— 手上是客户端导出的 .json 或 .xlsx
  ──────────────────────────────────────────────────────
  ※ 不重新分镜：镜头数、每镜时长一个不动，只改文字、人物、音色

  ◆ 场景 1：只改名 + 形象重做
      ▶ 你说：「这个爆款工程不用重新分镜，角色全部改名，形象重新设计」
      ✓ 得到：新工程 .json

  ◆ 场景 2：女频改男频
      ▶ 你说：「这个工程女频改男频，主角换成男的，形象重新设计」
      ✓ 得到：新工程 .json（剧情和分镜都审过）

  ◆ 场景 3：同一个工程有 .json 也有 .xlsx
      ▶ 你说：「用这个 .json 改，图片从 .xlsx 里补」

■ 交付物在辰屿客户端怎么用
  ──────────────────────────────────────────────────────
  剧本 + 形象表.json  →  新建项目贴剧本，在「人物设定与故事背景」上传形象表
                          → 客户端按表建人物/场景/道具卡 → 分镜 → 出视频
  新工程 .json        →  左侧边栏「导入」→ 资产页先出角色图 → 出视频
  ※ 积分：只有视频反推扣积分；写剧本、洗稿、形象设计、工程改写都不扣
  ※ 网络：连不上会自动改走系统代理；还不通就设置 CHENYU_PROXY=http://127.0.0.1:7890
  ※ 命令表：chenyu-pro help ｜ 只看一节：chenyu-pro guide 视频 / 改编 / 洗稿 / 形象 / 工程 / 交付
  ※ 升级：重新运行安装命令

```

洗稿不交半成品：Agent 写完后按"查 → 审 → 修 → 复查"循环，直到 `deliver-check` 输出 DELIVERY_PASS 才交付（附审核报告）。

账号与积分 KEY 请联系平台方获取。凭据只存本机 `~/.codex/chenyu-pro/config.json`。
